# Security Policy

## Supported version

ShadowRunnerNights is currently in design and engine experimentation; there is
no playable release. The current `main` branch is the supported version for
security reports concerning repository materials, build or packaging tooling,
and GitHub automation.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this
repository. Do not open a public issue for a suspected security vulnerability.

Include, where possible:

- a clear description of the issue and its potential impact;
- steps to reproduce or a minimal proof of concept;
- affected files, commits, or environments; and
- any suggested mitigation.

Reports will be acknowledged within seven calendar days. Please allow time for
assessment and remediation before public disclosure; coordinated disclosure
will be agreed with the reporter.

## Scope

This policy covers original materials and automation maintained in this
repository. It does not provide support for Neverwinter Nights, Neverwinter
Nights: Enhanced Edition, or other third-party software.

There is no bug bounty program.
