# Contributing to ShadowRunnerNights

Thank you for your interest in contributing. ShadowRunnerNights is currently a
design and engine-experimentation project; it does not yet contain a playable
module.

## Before contributing

For substantial proposals, open an Issue first to discuss the problem, project
fit, and expected scope. Small documentation corrections may be submitted
directly as pull requests.

Do not use public Issues for security vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.

## Contribution requirements

All contributions must be original or accompanied by clear, affirmative rights
to use and redistribute them. Do not submit:

- copied or adapted third-party rulebook text;
- proprietary game assets, art, audio, or source code;
- trademarks or other protected material without documented permission; or
- material taken from quarantined references or external repositories.

By submitting a pull request, you confirm that you have the right to submit
the contribution and agree to provide it under the repository's
[PolyForm Noncommercial License 1.0.0](LICENSE).

## Pull requests

Keep pull requests focused and explain both the change and its purpose.
Include tests or reproducible verification when applicable.

Implementation contributions should preserve the project direction described in
the README, especially deterministic rules logic that remains independent of
engine objects, persistence, clocks, configuration, and production randomness.

Maintain attribution and provenance information for any approved external
material. If a contribution adds a dependency or asset, identify its source
and applicable license in the pull request description.
